## 1. ブザー系のJIS記号を番号どおりに整理

### 動作仕様

参照資料により、JIS C 0617-8 の各番号の規格名は次のとおりと確認しました。

| JIS番号 | 規格名 |
|---|---|
| 08-10-01 | ランプ（一般用図記号） |
| 08-10-06 | **音響信号装置（一般用図記号）** |
| 08-10-09 | **サイレン** |
| 08-10-10 | **ブザー** |

これに合わせ、`buzzer` のデザイン（右パネル「ブザー形状」）を次のとおり整理しました。

| キー | 表示名 | 形状 |
|---|---|---|
| `jis0806` | 音響信号装置・一般（JIS C 0617 08-10-06） | 弦を下にした半円（**上ふくらみ**）＋弦の両端より少し内側から下ろす端子線2本 |
| `jis0810` | ブザー（JIS C 0617 08-10-10） | 08-10-06 の半円を**上下反転**（弦が上・弧が**下ふくらみ**）＋**弧の上から**下ろす端子線2本 |
| `siren` | サイレン・直角三角形（JIS C 0617 08-10-09） | §2 参照 |
| `horn` | ホーン（ラッパ形・略画） | 規格外の略画 |
| `speaker` | スピーカー（略画） | 規格外の略画 |
| `sound` | 半円＋音波（略画） | 規格外の略画 |
| `piezo` | 電子ブザー・箱＋半円（略画） | 規格外の略画 |

**共通の仕様（08-10-06 / 08-10-10 / 08-10-09 の3種）**

- **端子線ピッチは 2.5mm ちょうど**（2.5mmグリッドに整合）。端子線の x は 3.75 と 6.25。
  旧 `jis` は 2.4mm で 2.5mmグリッドに載っていなかったため、2.4mm → 2.5mm へ広げています。
- **接続点は端子線の下端2点**（y=6）。
- 既定寸法は 12×6mm。

**08-10-06 と 08-10-10 の違い**

- 08-10-06 は半円が**上ふくらみ**で、端子線は**弦から**下りる。
- 08-10-10 は半円が**下ふくらみ**で、端子線は**弧から**下りる。
  弦から下ろすと弧と交差してしまうためです。
  端子線の上端 y=4.43 は、弧（中心 [5,3]・半径 1.9）上の点 `3+√(1.9²−1.25²)=4.4309` に一致させてあり、
  **隙間も突き抜けもありません**。

**廃止したデザイン**

左右に水平リードを持つ「音響信号一般・半円＋線（旧キー `general`）」は、番号が 08-10-06 と重複するため**廃止**しました。
旧キー `jis` は `jis0806` へ改称しました。既存図面は移行処理で自動的に置き換わります（§15）。

### マニュアルへ

- §21.4 のブザー行を上表へ差し替え。**キー `jis` と `general` は本文に残さないでください**。
- §21.4 の「JISブザーは上向き半球の…」の記述で、**番号 08-10-06 は「音響信号装置（一般用図記号）」**であり、
  **08-10-10 だけが「ブザー」**であることを明記。端子線ピッチが 2.5mm である旨も1文追記。
- 08-10-06 と 08-10-10 の違い（半円の向きと端子線の起点）を2〜3文で説明。
  「08-10-06 は端子線が弦から、08-10-10 は端子線が弧から下りる」ことを明記してください。
- §21.5「配線接続点とグリッド」に、ブザー系3種の端子線ピッチが 2.5mm でグリッドに載ることを追記。
- ブザーの選択肢を列挙している箇所（改訂前 563行目付近「ブザーはホーン、スピーカー、JISブザー、音響信号一般、
  サイレン、発音強調、電子ブザーから選べます」）を、
  **「ホーン、スピーカー、音響信号装置（08-10-06）、ブザー（08-10-10）、サイレン（08-10-09）、発音強調、電子ブザー」**へ差し替え。

## 2. サイレン（08-10-09）の作図やり直し

### 動作仕様

配線上に横向きの直角三角形を置く形は誤りでした。正しい形へ作図し直しています。

- キー: `siren`（変更なし）
- 表示名: **サイレン・直角三角形（JIS C 0617 08-10-09）**
- 形状: **直角部を上にした直角二等辺三角形**。頂点 (5, 0.5)、底辺 (2.5, 3)–(7.5, 3)。
  頂点から出る2辺のベクトル (−2.5, 2.5) と (2.5, 2.5) は内積が 0 なので**直角**、長さも等しく**二等辺**です。
- 端子線: 底辺の両端より少し内側（x=3.75 / 6.25）から下ろす。**接続点は端子線の下端**。
- 端子線ピッチ 2.5mm。

### マニュアルへ

- §21.4 のサイレン行の説明を上記へ差し替え。「配線上に置く横向き三角形」という記述は**削除**。
- 「サイレンは直角三角形です」とだけ書いてある箇所（改訂前 1966行目付近）を、
  **直角部を上にした直角二等辺三角形＋下向き端子線2本**へ具体化。

## 3. 位置スイッチ 07-08-01 / 07-08-02 を追加

### 動作仕様

`limitSwitch` のデザイン選択肢へ2種を追加しました（既存4種と合わせて6種）。

| キー | 表示名 |
|---|---|
| `standard` | 箱形アクチュエータ（NO） |
| `nc` | 箱形・下側（NC/オーバーラン） |
| `jisNo` | **位置スイッチa接点（JIS C 0617 07-08-01）** |
| `jisNc` | **位置スイッチb接点（JIS C 0617 07-08-02）** |
| `roller` | ローラーレバー（NO） |
| `rollerNc` | ローラーレバー（NC） |

**JIS形2種の形状**

- 線だけのa接点／b接点（IEC形。b接点には止めの縦線あり）の**斜めの可動線に、直角三角形を直接密着**させます。
- 三角形は **30°-60°-90°の直角三角形**。**操作軸（縦線）はありません**。
- 三角形の一辺（頂点A→B）が**可動線の直線上に完全に載り**、可動線と密着します。
- **30°の頂点Aが接点の根元（可動線の始点）側**を向きます。Bが直角、Cが60°。
- **メーク接点（07-08-01）は可動線の上側**、**ブレーク接点（07-08-02）は可動線の下側**に三角形が付きます。
- 辺ABの長さは 1.3mm、BCは `1.3×tan30°≒0.75mm`。
- ブレーク接点の三角形は最大 x=5.9mm で、止めの縦線（x=6.1mm）より左に収まるため**止めと交差しません**。
- 既定寸法 10×6mm、接続点は左右2点（従来のリミットスイッチと共通）。

### マニュアルへ

- §21.4 のリミットスイッチ行へ2種を追加。説明は
  「線だけのa接点／b接点の**斜めの可動線に直角三角形が直接くっつく**形で、
  **30°の角が接点の根元を向く**。a接点は線の上側、b接点は線の下側」と書いてください。
- §6.2 の部品一覧で、リミットスイッチにJIS形があることに触れる。

## 4. 降伏ダイオードの番号是正と双方向性の追加

### 動作仕様

参照資料により、降伏ダイオードの番号は次のとおりと確認しました。

| JIS番号 | 名称 | 形状 | キー |
|---|---|---|---|
| **05-03-07** | 一方向性降伏ダイオード（＝一般にいうツェナーダイオード） | カソードバーの折り返しが**片側だけ** | `zener` |
| **05-03-06** | 双方向性降伏ダイオード | カソードバーの**両端を逆向きに折る** | `zenerBi`（**新規**） |

一方向性と双方向性の違いは、カソードバーの折り返しが片側か両側かだけです。
折れるのはバー上端（アノード側へ 0.45mm）で、下端は折らず直線のままです。
寸法・接続点は変更なし（10×4.4mm、左右ピン間隔10mm）。

`diode` のデザイン選択肢は次のとおりになりました。

| キー | 表示名 |
|---|---|
| `standard` | 半導体ダイオード（JIS 05-03-01） |
| `led` | 発光ダイオードLED（JIS 05-03-02） |
| `photo` | フォトダイオード（JIS 05-06-02） |
| `zener` | 一方向性降伏・ツェナー（JIS 05-03-07） |
| `zenerBi` | **双方向性降伏（JIS 05-03-06）** |
| `thyristor` | サイリスタ（JIS 05-04-06・ゲート線） |
| `bridge` | ブリッジ整流（JIS 06-14-04・◇4端子） |
| `triac` | トライアック（JIS 05-04-11） |

### マニュアルへ

- §21.4 のダイオード行を上表へ差し替え。
- 「一方向性と双方向性の違いは、カソードバーの折り返しが片側か両側かだけ」と1文添えてください。
- 図でZ形（両側折れ）を「ツェナー」として載せている場合は、**双方向性降伏**へ言い換えるか差し替え。

## 13. シンボル拡大の倍率を選べるようにした

### 動作仕様

右パネル「ページ設定」の**シンボル拡大**が、チェックボックスから**セレクト**に変わりました。

| 項目 | 旧 | 新 |
|---|---|---|
| UI | チェックボックス（ON=1.5倍） | セレクト `#symbolScaleSelect` |
| 選べる倍率 | 1.5倍のみ | **なし（等倍）／1.5倍／2倍／2.5倍／3倍** |
| 保存値 `page.symbolScale` | 真偽値 | **数値**（1 / 1.5 / 2 / 2.5 / 3） |

- 倍率は**そのページの新規配置分にだけ**適用されます（既存の部品は変わりません）。
- 等倍を選ぶと要素に `scale` を持たせません（従来データと同じ形のまま）。
- 接続ピン・DXF出力も倍率に追従します。例: a接点のピン間隔は 10mm → 3倍で 30mm。
- 旧データの `symbolScale: true` は **1.5倍**として読み、schemaVersion 6 で数値へ書き換えます。

### マニュアルへ

- §3.5「右パネル」および §18「標準設定」でシンボル拡大に触れている箇所を、
  **チェックボックス → セレクト（5段階）** へ書き換え。
- 「1.5倍」と固定で書いている箇所（§21.5 付近など）を「選んだ倍率」に一般化し、
  選択肢が **なし/1.5/2/2.5/3** であることを明記。
- 「既存の部品は変わらない」「接続ピン・DXFも倍率に追従する」の2点は残してください。

## 14. 端子箱の寸法を数値で指定できるようにした

### 動作仕様

右パネル（端子箱を選択時）に寸法欄が増えました。

| 欄 | フィールド | 内容 |
|---|---|---|
| 1箱の高さ mm | `boxCellHeight` | 端子1個分の区画の高さ。**空欄なら従来どおり全高を箱数で等分** |
| 箱の幅 mm | `w` | 箱の外形幅 |
| 引き出し線の長さ mm | `boxStubLength` | 左右の引き出し線の長さ。既定6mm、**0にすると線が消える** |

- **1箱の高さ**または**箱の数**を変えると、外形の高さが自動で「1箱の高さ×箱の数」へ追従します。
  欄の下に計算後の高さが表示されます。
- 変更時は**第1接続ピンの絶対位置を保持**するため、接続済みの配線はずれません。
- 引き出し線の長さを0にすると、引き出し線の描画がなくなり、**箱の横辺だけが接続点**になります。
- 端子中心は区画の中央です（例: 1箱8mm×4箱なら 4／12／20／28mm）。
- SVG・DXF・接続点のすべてが同じ寸法計算を共有します。

### マニュアルへ

- §10.2b「端子箱」へ上記3欄の説明を追加。機器箱（§11.1）の
  「端子ピッチと上下マージンを指定すると外形が追従する」と同じ書き方に揃えてください。
- §21.5 のピン間隔表に端子箱の行があれば、「1箱の高さを指定すると外形が追従」する旨を追記。
- 引き出し線を0にしたときの接続点の挙動（箱の横辺だけになる）を1文で明記。

## 15. 保存データの移行（schemaVersion 4 → 6）

### 動作仕様

`SCHEMA_VERSION` を 4 → **6** へ上げました。旧データは読み込み時に自動移行されます。

**4 → 5: ブザー系のバリアント整理**

| 旧 `buzzerVariant` | 新 | 配線・接続点の追従 |
|---|---|---|
| `jis` | `jis0806` | 端子線ピッチ 2.4→2.5mm の差分だけ新ピンへ移動 |
| `general` | `jis0806` | 左右の水平リード位置から**下向き2ピン**へ移動 |
| `siren` | `siren` | 左右の水平リード位置から**下向き2ピン**へ移動 |
| `horn` / `speaker` / `sound` / `piezo` | 変更なし | 移動なし |

**5 → 6: 廃止種別の置き換えと拡大倍率の数値化**

| 対象 | 移行内容 |
|---|---|
| `page.symbolScale` | 真偽値 → 数値（`true`→1.5、`false`→1） |
| `beacon`（回転灯） | `lamp`（表示灯）へ。要素原点を2.2mm下げて接続点の絶対位置を保つ |
| `bell`（ベル） | `buzzer` / `jis0806` へ。配線・接続点も下向き2ピンへ追従 |
| `contactor3p`（電磁接触器 主接点3極） | **単極のa接点（`contactNO`・縦向き）3個へ分解**。各極の接続点は元の位置のまま |

旧ピンへ接続していた配線（`wire` / `line` / `arrow` / `mechanicalLink`）と接続点（`junction`）は
新ピンへ自動で追従します。**配線の反対側の端点は動きません。**
再適用しても結果が変わらないこと（冪等性）をテストで確認済みです。

> `contactor3p` は一度だけ実装して同日中に廃止した種別です（付録A-3）。
> パレットには存在しないため、**マニュアルには書かないでください**。移行処理だけが残っています。

### マニュアルへ

- §16.2「JSON読込」に、古いデータを開くと**ブザーの形状名と端子位置、回転灯・ベルの種別が自動更新される**旨を追記。
- §16 冒頭またはトラブル対応へ、「本アプリで保存し直すと schemaVersion 6 になり、
  旧版のアプリでは開けなくなる」旨の注意を1文。既に同種の記述があればバージョン番号のみ更新。
- 本文中に schemaVersion の現行値を書いている箇所があれば **6** へ更新。
