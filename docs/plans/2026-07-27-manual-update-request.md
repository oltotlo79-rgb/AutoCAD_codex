## 1. ブザーのJIS記号の番号是正（08-10-10 → 08-10-06）

### 動作仕様

これまで「JIS C 0617 08-10-10」として提供していた**上ふくらみ半円＋下向き端子線2本**の記号は、
正しくは **08-10-06** でした。番号を是正し、バリアントキーも改称しています。

| 区分 | 旧 | 新 |
|---|---|---|
| バリアントキー | `jis` | `jis0806` |
| 右パネルの表示名 | ブザー・半円（JIS C 0617 08-10-10） | **ブザー・半円（JIS C 0617 08-10-06）** |
| 形状 | 弦を下にした半円（上ふくらみ）＋弦の内側から下ろす端子線2本 | 変更なし |
| 端子線ピッチ | 2.4mm | **2.5mm**（2.5mmグリッド整合） |
| 接続点 | 端子線の下端2点 | 変更なし |

### マニュアルへ

- §21.4 のブザー行（現 1956行目付近の表）で `jis` → `jis0806`、番号 08-10-10 → **08-10-06** へ修正。
- 1966行目付近の「JISブザーは上向き半球の…」の記述で、番号を 08-10-06 と明記し、
  **端子線ピッチが2.5mm**である旨を1文追記。
- §21.5 の「配線接続点とグリッド」に、ブザー系3種の端子線ピッチが 2.5mm でグリッドに載ることを追記。

## 2. 08-10-10 を新設（半円を上下反転した形）

### 動作仕様

正しい **08-10-10** は、08-10-06 の半円を**上下反転**した形です。新バリアントとして追加しました。

- バリアントキー: `jis0810`
- 右パネル表示名: **ブザー・半円反転（JIS C 0617 08-10-10）**
- 形状: **弦が上・弧が下ふくらみ**（弧の掃引を 180→360 から 0→180 へ反転）
- 端子線: **弧の上から下ろす**（弦から下ろすと弧と交差するため）。上端 y=4.43 は
  弧（中心 [5,3]・半径1.9）上の点 `3+√(1.9²−1.25²)=4.4309` に一致させてあり、**隙間も突き抜けもありません**
- 端子線ピッチ 2.5mm、接続点は端子線の下端2点（08-10-06 と共通）

### マニュアルへ

- §21.4 のブザー行へ `jis0810`（08-10-10・半円反転）を追加。
- 08-10-06 と 08-10-10 の違い（半円の向きと端子線の起点）を2〜3文で説明。
  「08-10-06 は端子線が弦から、08-10-10 は端子線が弧から下りる」ことを明記してください。

## 4. サイレン（08-10-09）の作図やり直し

### 動作仕様

配線上に横向きの直角三角形を置く形は誤りでした。正しい形へ作図し直しています。

- バリアントキー: `siren`（変更なし）
- 右パネル表示名: **サイレン・直角三角形（JIS C 0617 08-10-09）**
- 形状: **直角部を上にした直角二等辺三角形**。頂点 (5, 0.5)、底辺 (2.5, 3)–(7.5, 3)。
  頂点から出る2辺のベクトル (−2.5, 2.5) と (2.5, 2.5) は内積が 0 なので**直角**、長さも等しく**二等辺**
- 端子線: 底辺の両端より少し内側（x=3.75 / 6.25）から下ろす。**接続点は端子線の下端**
- 端子線ピッチ 2.5mm

### マニュアルへ

- §21.4 のサイレン行の説明を上記へ差し替え。「配線上に置く横向き三角形」という記述は削除。
- 1966行目付近の「サイレンは直角三角形です」を、**直角部を上にした直角二等辺三角形＋下向き端子線2本**へ具体化。

## 5. 保存データの移行（schemaVersion 4 → 5）

### 動作仕様

`SCHEMA_VERSION` を 4 → **5** へ上げ、旧データを自動移行します。

| 旧 `buzzerVariant` | 新 | 配線・接続点の追従 |
|---|---|---|
| `jis` | `jis0806` | 端子線ピッチ 2.4→2.5mm の差分だけ新ピンへ移動 |
| `general` | `jis0806` | 左右の水平リード位置から**下向き2ピン**へ移動 |
| `siren` | `siren` | 左右の水平リード位置から**下向き2ピン**へ移動 |
| `horn` / `speaker` / `sound` / `piezo` | 変更なし | 移動なし |

旧ピンへ接続していた配線（`wire` / `line` / `arrow` / `mechanicalLink`）と接続点（`junction`）は
新ピンへ自動で追従します。**配線の反対側の端点は動きません。**
再適用しても結果が変わらないこと（冪等性）をテストで確認済みです。

### マニュアルへ

- §16.2「JSON読込」に、v4以前のデータを開くと**ブザーの形状名と端子位置が自動更新される**旨を追記。
- §16 冒頭またはトラブル対応へ、「本アプリで保存し直すと schemaVersion 5 になり、
  旧版のアプリでは開けなくなる」旨の注意を1文。既に同種の記述があればバージョン番号のみ更新。
- 本文中に schemaVersion の現行値を書いている箇所があれば **5** へ更新。

## 8. 新規シンボル: 電磁接触器 主接点3極（JIS C 0617-7）

### 動作仕様

- 部品種別: `contactor3p` / パレット名「**電磁接触器 主接点3極**」/ パレット分類「接点・スイッチ」
- 既定寸法 30×10mm、既定ラベル `MC`、タグ接頭辞 `MC`
- 縦向きのa接点（斜め可動線＋接触器機能記号の半円）を**10mmピッチで3極**配置
- 接続点は**6点**（各極の上下）。x = 5 / 15 / 25、y = 0 / 10。**ピンピッチ10mm＝2.5mmグリッドの倍数**
- 可動線の先端どうしを**破線（機械連動）**で結ぶ。破線 y=6.4 は半円の頂点 y=6.6 より上を通るため
  **半円とは交差せず**、両端の極では可動線の先端に正確に接する
- 配置時は中心合わせ（`centerPlacedTypes`）

### マニュアルへ

- §6.2 の一覧へ追加。
- §19「よくある操作」へ、主回路（動力回路）の作図に使う旨を1〜2文。
- §21.5 の「主なシンボルのピン間隔」表（現 2024行目付近）へ
  「電磁接触器 主接点3極 | 既定30×10mm、極ピッチ10mm、接続ピン6点」を追加。

## 12. 実装側の検証状況（参考）

マニュアル記述の裏付けとして、以下は自動テストで確認済みです（`tests/index.spec.js`）。

- ブザー3種の接続ピン間隔が **2.5mm ちょうど**であること
- 08-10-06 の弧が 180→360、08-10-10 の弧が 0→180 であること
- 08-10-10 の端子線上端が**弧の上に載る**こと（中心からの距離＝半径、誤差0.01mm未満）
- 端子線の下端が接続点と一致すること（線の切れがない）
- v4→v5 移行で配線・接続点が新ピンへ追従し、**再適用しても変化しない**こと
- 追加記号14種すべてが**要素枠からはみ出さない**こと
- 主接点3極の機械連動破線が両端の可動線先端に一致し、半円と交差しないこと
- DXF に弧と DASHED 線種が出力されること
