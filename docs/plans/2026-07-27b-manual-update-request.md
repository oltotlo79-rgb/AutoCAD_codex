## 1. シンボル拡大の倍率を選べるようにした

### 動作仕様

右パネル「ページ設定」の**シンボル拡大**が、チェックボックスから**セレクト**に変わりました。

| 項目 | 旧 | 新 |
|---|---|---|
| UI | チェックボックス（ON=1.5倍） | セレクト `#symbolScaleSelect` |
| 選べる倍率 | 1.5倍のみ | **なし（等倍）／1.5倍／2倍／2.5倍／3倍** |
| 保存値 `page.symbolScale` | 真偽値 | **数値**（1 / 1.5 / 2 / 2.5 / 3） |

- 倍率は**そのページの新規配置分にだけ**適用されます（既存の部品は変わりません）。
- 等倍を選ぶと要素に `scale` を持たせません（従来データと同じ形のまま）。
- 接続ピン・DXF出力も倍率に追従します。例: a接点のピン間隔は 10mm → 3倍で 30mm。
- 旧データの `symbolScale: true` は **1.5倍**として読み、schemaVersion 6 で数値へ書き換えます。

### マニュアルへ

- §3.5「右パネル」および §18「標準設定」でシンボル拡大に触れている箇所を、
  **チェックボックス → セレクト（5段階）** へ書き換え。
- 「1.5倍」と固定で書いている箇所（§21.5 付近など）を「選んだ倍率」に一般化し、
  選択肢が **なし/1.5/2/2.5/3** であることを明記。
- 「既存の部品は変わらない」「接続ピン・DXFも倍率に追従する」の2点は残してください。

## 2. 回転灯・ベル・電磁接触器 主接点3極を廃止

### 動作仕様

以下の3種別をパレットから削除しました。

|---|---|---|
| `beacon` | 回転灯 | **表示灯（`lamp`）**。接続点の絶対位置が変わらないよう要素原点を2.2mm下げる |

### マニュアルへ

- 前依頼書 §8（電磁接触器 主接点3極）は**反映しない**。§21.5 のピン間隔表にも追加しないこと。
- §16.2「JSON読込」に、v5以前のデータを開くと回転灯→表示灯・ベル→ブザー・

## 3. ツェナーダイオードの是正（JIS C 0617-5, 05-03-06）

### 動作仕様

カソードバーの**両端**を逆向きに折り曲げていた（Z形になっていた）のは誤りでした。
規格どおり**片側だけ**を折るよう修正しました。

- 折れるのはバー上端のみ（アノード側へ 0.45mm）。下端は折らず直線のまま。
- 寸法・接続点は変更なし（10×4.4mm、左右ピン間隔10mm）。

### マニュアルへ

- §21.4 のダイオード行の「ツェナー」の説明に、**カソードバーの折れは片側だけ**（05-03-06）と明記。
- 図でZ形のツェナーを載せている場合は差し替え。

## 4. サイリスタ／トライアックのゲート線に接続点を追加

### 動作仕様

ゲート線の先端に接続点がなく、**ゲート回路の配線ができませんでした**。第3の接続点を追加しました。

| バリアント | 接続点 |
|---|---|
| `thyristor`（サイリスタ） | 左右2点＋**ゲート線先端(7.6, 4.4)** の計3点 |
| `triac`（トライアック） | 左右2点＋**ゲート線先端(7.8, 4.6)** の計3点 |

形状そのものは変更していません。

### マニュアルへ

- §21.4 のダイオード行で、サイリスタ・トライアックは**ゲート線の先端からも配線できる**ことを明記。
- §9.8「端点スナップ」の吸着先の列挙に「サイリスタ／トライアックのゲート端」を加えても構いません。

## 5. トランジスタに「外囲みの円なし」を追加

### 動作仕様

`transistor` のデザイン選択肢が2種→4種になりました。

| キー | 表示名 |
|---|---|
| `npn` | NPN（外囲みの円あり） |
| `pnp` | PNP（外囲みの円あり） |
| `npnPlain` | **NPN（円なし）** |
| `pnpPlain` | **PNP（円なし）** |

円なし版は封止を表す円を省いただけで、**寸法・接続点3点（ベース／コレクタ／エミッタ）は円ありと共通**です。

### マニュアルへ

- §21.4 のトランジスタ行へ4種を記載。既存の「NPN」「PNP」の表示名も
  「（外囲みの円あり）」付きへ更新。

## 6. リミットスイッチにJIS形（07-08-01 / 07-08-02）を追加

### 動作仕様

`limitSwitch` のデザイン選択肢へ2種を追加しました。

| キー | 表示名 | 形状 |
|---|---|---|
| `jisNo` | 位置スイッチa接点（JIS C 0617 07-08-01） | 線だけのa接点（IEC形）＋可動線の中点から下ろした操作軸＋その先の三角形 |
| `jisNc` | 位置スイッチb接点（JIS C 0617 07-08-02） | 線だけのb接点（IEC形・止め付き）＋操作軸＋三角形 |

- 既定寸法 10×6mm、接続点は左右2点（従来のリミットスイッチと共通）。
- 操作軸は固定接点の線が切れている区間を通るため、**他の線と交差しません**。

### マニュアルへ

- §21.4 のリミットスイッチ行へ2種を追加（既存4種と合わせて6種）。
- §6.2 の部品一覧で、リミットスイッチにJIS形があることに触れる。

## 8. 端子箱の寸法を数値で指定できるようにした

### 動作仕様

右パネル（端子箱を選択時）に寸法欄が増えました。

| 欄 | フィールド | 内容 |
|---|---|---|
| 1箱の高さ mm | `boxCellHeight` | 端子1個分の区画の高さ。**空欄なら従来どおり全高を箱数で等分** |
| 箱の幅 mm | `w` | 箱の外形幅 |
| 引き出し線の長さ mm | `boxStubLength` | 左右の引き出し線の長さ。既定6mm、**0にすると線が消える** |

- **1箱の高さ**または**箱の数**を変えると、外形の高さが自動で「1箱の高さ×箱の数」へ追従します。
  欄の下に計算後の高さが表示されます。
- 変更時は**第1接続ピンの絶対位置を保持**するため、接続済みの配線はずれません。
- 引き出し線の長さを0にすると、引き出し線の描画がなくなり、**箱の横辺だけが接続点**になります。
- 端子中心は区画の中央です（例: 1箱8mm×4箱なら 4／12／20／28mm）。
- SVG・DXF・接続点のすべてが同じ寸法計算を共有します。

### マニュアルへ

- §10.2b「端子箱」へ上記3欄の説明を追加。機器箱（§11.1）の
  「端子ピッチと上下マージンを指定すると外形が追従する」と同じ書き方に揃えてください。
- §21.5 のピン間隔表に端子箱の行があれば、「1箱の高さを指定すると外形が追従」する旨を追記。
- 引き出し線を0にしたときの接続点の挙動（箱の横辺だけになる）を1文で明記。

## 12. 実装側の検証状況（参考）

`tests/index.spec.js` で以下を自動確認しています。

- シンボル拡大の選択肢が `1 / 1.5 / 2 / 2.5 / 3` で、各倍率どおりに接続ピン間隔が変わること
- 等倍では要素に `scale` が付かないこと、セレクトが保存値へ追従すること
- 追加記号（限定図記号・操作機構・発電機・位置スイッチ2種・リード縦バー2種・トランジスタ円なし2種）が
  **要素枠からはみ出さない**こと
- 位置スイッチ・リード縦バーの接続点が2点、リード縦バーのピン間隔が15mmであること
- トランジスタ円なし版の接続点が円ありと同一の3点であること
- ツェナーの折れが片側だけ（プリミティブ数6）であること
- サイリスタ・トライアックの接続点が3点であること
- 端子箱で1箱の高さ8mm×4箱＝32mmへ外形が追従し、端子中心が4/12/20/28mmになること
- 端子箱の第1接続ピンの絶対位置が寸法変更後も保持されること
- 引き出し線0mmで線が消え、接続点が箱の辺だけになること
