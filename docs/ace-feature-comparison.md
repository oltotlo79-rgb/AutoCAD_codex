# AutoCAD Electrical との機能対照表（Electrical Drawing Studio）

対象バージョン: `index.html`（2026-07-26 時点 / schemaVersion 4）
比較対象: AutoCAD Electrical（以下 **ACE**）の標準機能

凡例

| 記号 | 意味 |
|---|---|
| **○** | 同等のことができる（実装済み・実機で動作確認済み） |
| **△** | 一部できる／別のやり方で代替できる（制限あり） |
| **×** | できない（実装なし） |

> 本書の「○」は、実ブラウザでの動作確認（機能メニュー66項目・全78部品種別・
> テンプレート12種・取込7経路・出力8経路の総当たり）に基づいています。
> ACE側の機能名は日本語版の呼称を基本とし、判別しやすい項目には英語名を併記しています。

---

## 0. 位置づけの違い（最初に読んでください）

| 観点 | ACE | 本ツール |
|---|---|---|
| 基盤 | AutoCAD（DWG）+ 電気設計アドオン | ブラウザ単体（HTML1ファイル）+ 独自JSON |
| プロジェクト | フォルダ＋`.wdp`（複数DWGの束） | **1つのJSONに複数ページ**（=図面）を保持 |
| 図面の実体 | DWG（ブロック＋属性で「賢い」図面） | SVG描画＋要素データ（DXFは**出力/取込とも図形のみ**） |
| 導入 | インストール・ライセンス必要 | **インストール不要**・オフライン動作 |
| 想定用途 | 設計事務所・盤メーカーの本格運用 | 現場・小規模盤の作図と、既存図の再作図・確認 |

**最大の違いは「DWGネイティブでない」ことです。** ACEの資産（ブロック・属性・
既存DWG）をそのまま読み書きすることはできません。図形としてのDXF往復のみ可能です。

## 1. プロジェクト・図面管理

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| プロジェクトマネージャ（`.wdp`・図面リスト） | △ | 1JSON内の**ページ一覧**が相当。ページ追加/複製/削除/並べ替え、ページナビゲータ（サムネイル・D&D並べ替え）あり。複数プロジェクトは「プロジェクト管理（ブラウザ内保存）」で切替 |
| 図面プロパティ（図面ごとの設定継承） | △ | ページごとに用紙・図枠・表題欄・設備/場所コードを保持。ACEのような「プロジェクト既定→図面継承」の階層はない |
| 図面テンプレート（DWT） | ○ | 「テンプレートからページ追加」12種（設備ラダー/AC受電/ACモータ/DC電源/PLC電源/セーフティ/PLC入出力/端子接続図/インターロック/汎用ラダー/目次/機器配置） |
| シート番号・総ページ数の自動更新 | ○ | 表題欄一括更新でシート番号・`シート/総数`をマッピング。ページ増減で自動同期 |
| 図面の並べ替え（プロジェクト内） | ○ | 「前へ/後へ」「ページ順」直接入力、並べて表示中は見出しの◀▶ |
| 複数図面を同時に開いて編集 | ○ | 「並べて表示（横/縦）」で全ページを並べ、どのページも直接編集可 |
| プロジェクト全体の一括処理 | ○ | 「プロジェクト一括更新」（タグ再採番・線番更新・接続点生成・頁情報・盤同期・監査）。Undo1回で戻せる |
| Vault / PDM連携・チェックイン | × | なし。JSONファイルの受け渡しで運用 |
| マルチユーザー同時編集・排他制御 | × | なし（1人1ファイル） |
| 図面テンプレートの社内標準配布 | ○ | 「標準パック」（線番書式・タグ規則・配線種別・レイヤ・監査ルール・ユーザー部品・カタログ・表題欄レイアウト）をJSONで入出力 |

## 2. 図枠・表題欄

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| 図枠（ボーダー）の選択 | ○ | 6種（ラダー/基本/詳細/側面/目次・表紙/枠線のみ）。用紙はA4・A3、縦横 |
| 表題欄の属性割付（Title Block Setup） | ○ | 「表題欄レイアウト編集（JSON）」で罫線・欄配置を自社様式へ変更可。標準パックで配布 |
| 表題欄の一括更新（Title Block Update） | ○ | 全ページ/現在ページ、項目ごとの参照元マッピング（プロジェクト値/ページ名/シート番号/シート番号/総数/空欄/既存保持）、「空欄のみ更新」 |
| 改訂欄・改訂履歴 | ○ | 改訂履歴（記号・日付・内容）を登録、詳細図枠の改訂欄へ最新5件表示。改訂三角＋雲マーク部品あり |
| 行番号（ラダー参照番号）付き図枠 | ○ | ラダー図枠に行番号00〜20（9.5mmピッチ）＋磁気スナップ |
| 図枠内クロスリファレンス表・機器符号表 | ○ | ラダー図枠の左下（接点位置一覧）・右下（機器タグ一覧）へ自動記入 |
| 用紙サイズ多数（A0〜、ANSI等） | × | A4/A3のみ |

## 3. シンボルライブラリ・部品挿入

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| 標準シンボルライブラリ（JIC/IEC/JIS/GB…） | △ | **78種別・シンボルデザイン100種類以上**を内蔵（JIS C 0617系の接点/操作スイッチ/保護器具/変成器/回転機/表示警報/受動素子/半導体/接地/論理ゲート）。ACEのような数千点のライブラリではない |
| アイコンメニューからの部品挿入 | ○ | 左パレット（カテゴリ別・検索・最近使用・お気に入り☆）。ドラッグ配置とクリック連続配置 |
| 挿入時のカタログ割付（Insert Component→カタログ検索） | △ | 配置後に「カタログから選択」で適用。挿入ダイアログでの検索は無い |
| 親子部品（親コイル・子接点）の関連 | ○ | 同一タグのコイル/接点でクロスリファレンス。参照アドレスは頁+行2桁 |
| シンボルの向き・ミラー | ○ | 90°回転、**左右ミラー**（記号自体を反転。表示・DXF・接続点が同時に反転） |
| ユーザー定義シンボルの作成（Symbol Builder） | ○ | 「シンボルビルダー」でマウス作図（線/矩形/円/楕円/円弧/文字/接続点、変形ハンドル、1/0.5/0.25mmスナップ）＋スクリプト定義の双方向編集。ユーザー部品として登録・編集 |
| 回路のコピー（Copy Circuit / 回路ビルダー） | ○ | 「回路ライブラリ」（自己保持・起動停止・タイマ・ランプ・ブザー・非常停止の組立済み回路）と「ユーザー回路登録/挿入」 |
| 部品の属性（ユーザー定義属性） | △ | タグ/説明/設備/場所/メーカー/品番/定格/項目＋属性メモ。任意名の属性追加は不可 |
| 部品の図面上属性表示（Attribute display） | ○ | 「図面表示」で表示項目・表示X/Y・文字サイズを個別指定 |
| 部品の置換（Swap/Update Block） | ○ | 「シンボル一括置換」（選択/現在ページ同種/全ページ同種、属性・回転・ラベル位置を維持、配線端も追従） |
| シンボルの拡大縮小 | △ | ページ設定の「シンボル拡大（1.5倍）」と固定形状以外のリサイズ。任意倍率の個別指定は不可 |

## 4. ラダー・回路作図

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| ラダー挿入（Insert Ladder：母線＋ラング） | ○ | 「設備ラダー」「ラダー（汎用）」テンプレート、レール名・本数指定 |
| ラング追加・行番号自動 | ○ | 「ラング追加」、設備図枠の行番号00〜20 |
| 行の挿入・削除（Insert/Delete Rung、要素の押し出し） | ○ | 「行挿入/行削除（行シフト）」。縦レールは自動で伸縮、行上に部品があれば中止して警告 |
| 複数ラダー・複数母線 | △ | 設備ラダーは左レール複数可。ACEの「ラダー参照系統を複数管理」ほどではない |
| 3相ラダー・多線図 | △ | AC受電/モータテンプレートが3相回路を生成。汎用の多線ラダー機能は無い |
| 回路の自動生成（Circuit Builder：モータ回路等） | ○ | 一括生成10種（ラング回路/非常停止チェーン/電源投入/ブレーキ整流/縦配線列/横配線行/ツイストペア/モータ分岐/PLCユニット/盤レイアウト連携）＋テンプレート12種 |
| 部品の整列・移動（Scoot / Align） | △ | 整列8種（左中右上中央下・横縦均等）、接続点スマート整列、1mm/5mm移動。ACEの「Scoot（配線に沿って滑らせる）」は無いが、移動時に接続配線が追従する |

## 5. 配線（ワイヤ）

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| ワイヤ挿入（直交・自動接続） | ○ | Wキー→ドラッグで直交配線。端子・接点へ吸着。Shiftで折れ向き反転、スペース/1〜4でL字2種・コの字2種を巡回 |
| 複数ワイヤの一括挿入（Multiple Wire Bus） | ○ | 「縦配線列」「横配線行」（本数・開始・ピッチ・線番接頭辞・開始番号）。用紙外は生成せず理由を表示 |
| ワイヤのトリム／延長／分割／結合 | ○ | 「終点を延長」「終点をトリム」「配線を分割」「配線を結合（2本選択）」 |
| ワイヤの折れ点編集 | ○ | 「曲がり角追加」「最後の曲がり角削除」「直交整形」「折れ向き反転」、□ハンドルのドラッグと座標入力 |
| 交差部のギャップ（ループ／ギャップ表示） | ○ | 「中央ギャップ追加」「交差ギャップ追加」（接続点のある交点は対象外）。DXFでは線分分割で表現 |
| ワイヤ種別（レイヤ・色・線幅・破線） | ○ | 配線種別管理（名称/色/線幅/破線/自動線番対象外）、種別追加可 |
| ワイヤ番号の自動採番 | ○ | §6参照 |
| 接続点（ドット）の自動生成 | ○ | 「接続点生成」（端点共有・直交交差）。端点個別表示のON/OFFも可 |
| 信号の送り／受け（Source/Destination Arrow） | ○ | 信号矢印（参照/発信元/受信先）。同名ラベルでページ横断のネット統合・相手頁注記 |
| ケーブルマーカー・シールド | ○ | ケーブルマーカー部品＋ケーブル・芯線エディタ（芯番号/芯色/線径/使用予備/From/To/シールド）＋ファンイン・ファンアウト生成 |
| ワイヤのFrom-To情報 | ○ | 配線ごとのFROM/TO手動指定＋自動推定、一覧編集、`wire-from-to.csv`出力 |
| 3相ワイヤ・多線バス専用コマンド | △ | テンプレートが3相回路を生成。汎用の「多線バス」コマンドは無い |
| ワイヤのスプライス（接続点部品） | △ | 接続点（junction）部品はあるが、ACEのスプライス管理属性は無い |

## 6. 線番（ワイヤ番号）

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| 線番の自動採番（ネット単位） | ○ | 端点一致・T分岐・接続点でネット判定し、1ネット1線番。代表1本のみ表示 |
| 採番書式（シート・連番・参照ベース） | ○ | `%S`シート/`%P`ページ名/`%D`図番/`%I`設備/`%L`場所/`%R`行番号2桁/`%N`連番。例 `%S%R`＝頁+行式 |

| 端子番号の自動採番 | ○ | 「端子番号の振り直し」（選択端子/ページ全体、開始番号・接頭辞） |

## 7. 部品タグ・クロスリファレンス

| ACEの機能 | 対応 | 本ツールでの状況 |
|---|---|---|
| 部品タグの自動採番（Retag） | ○ | `%F`ファミリ接頭辞/`%N`連番/`%S`/`%P`/`%D`/`%I`/`%L`。開始番号指定、`%N`欠落時は自動補完 |
| ファミリ接頭辞の編集 | ○ | 「部品タグ規則」（a接点=CR、押しボタン=PB、ランプ=PL 等。空欄にすると採番対象外） |
| タグの固定 | ○ | 「部品タグ固定」で再採番から除外 |
| コイル⇔接点のクロスリファレンス | ○ | 同一タグで自動。参照アドレス＝頁+行2桁。接点下に親コイル位置を自動表示（手動上書き可） |
| 図枠内クロスリファレンス表 | ○ | ラダー図枠の左下表（b接点は下線）・右下機器符号表 |
| 接点使用数の上限チェック | ○ | 部品カタログのa/b接点上限（既定4）を監査で検査 |
| 参照先へのジャンプ（Surfer） | ○ | 右パネルの「親コイルへ移動」「接点へ移動」、クロス参照/検索/監査の「選択」で自動スクロール。Alt+←/→で移動履歴 |
| 親子コンポーネントの多段構成 | △ | コイル/接点の対応のみ。ACEの汎用的な親子（複数子・ピン割付）管理は無い |

## 18. ACEにあって本ツールに無い主な機能（まとめ）

**設計データの根幹**
1. **DWGネイティブ**での保存・受け渡し（ACE資産の直接利用）
2. ブロック＋属性による「賢い図面」構造（DXF出力は図形のみ）
3. 外部参照・ペーパー空間・プロットスタイル

**大規模運用**
4. Vault等のPDM連携、マルチユーザー同時編集・排他
5. メーカー提供の大規模カタログ／フットプリントライブラリ
6. AutoLISP/.NET等のAPIによる自動化・社内ツール開発

**専門機能**
7. 油圧・空圧・P&ID記号ライブラリと専用作図
8. 単線結線図（One-line）専用コマンド群
9. ハーネス設計・マーシャリング・スプライス管理
10. 3D盤レイアウト・干渉チェック
11. ラダー参照系統の高度な管理（複数ラダー・区間参照）
12. 帳票フォーマット定義ファイルによる出力様式の自由設計

## 19. 本ツールが得意なこと（ACEに対する優位点）

1. **インストール不要・オフライン**（`index.html` 1つ。現場PCやタブレットでもすぐ動く）
2. **学習コストが低い**（置く→つなぐ→印刷。取扱説明書＋チュートリアル付き）
3. **日本のラダー様式に最初から対応**（行番号00〜20の9.5mmピッチ図枠、機器符号表、頁+行の参照、JIS C 0617記号）
4. **テンプレートからの一括生成が強力**（AC受電・ACモータ・DC電源・PLC電源・セーフティ・PLC入出力などを設定ダイアログから丸ごと生成）
5. **接続点が2.5mm方眼へ厳密整列**（配置・移動・複製のいずれでもピンが格子に乗る）
6. **図面差分・履歴タイムライン**（旧版JSONとの重ね比較、最大60件の操作履歴から任意時点へ復帰）
7. **1ファイル＝1プロジェクト**（JSON1つを渡せば図面・ユーザー部品・標準設定がすべて揃う）
