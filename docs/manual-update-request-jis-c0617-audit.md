## A. 今回の変更点（マニュアル修正が必要）

### A-1. 変圧器の JIS 形を規格の単線図どおりに作り直し、3巻き2種を追加 ★重要・破壊的変更あり

変圧器のシンボルデザインが **3種 → 7種** になりました。
JIS C 0617 の変圧器は**単線図（各巻線から必要な本数だけ線を出す形）**で規定されており、
従来の実装のように「左右4ピン＋上タップ2本」を一律に生やす形は規格と異なっていました。

| 値 | 表示名 | 形状と接続点 |
|---|---|---|
| `standard` | 巻線バー＋タップ（設備標準） | 変更なし。見本PDF実測形。左右15mm・上下9.5mm・上タップ2本の**6接続点** |
| `circles` | 2巻き変圧器・円形（JIS 06-09-01） | **作り直し**。縦に重なる円2個（半径3.4mm・中心間4.0mm＝直径の約4割が重なる）。**上の円の上へ1本／下の円の下へ1本だけ**。**接続点は上下の2点**、ピン間隔17.5mm |
| `circlesCore` | 2巻き変圧器・円形＋磁心（JIS 06-09-01） | 上記＋巻線間に磁心の**直線1本**（JIS の磁心は1本線。2本線は旧JIS表記） |
| `coils` | 2巻き変圧器・巻線形（JIS 06-09-02） | **作り直し**。半円コブ4個（半径1.25mm）の巻線2組を**凸側が向かい合う向き**に、巻線間5mm（コブ先端の隙間2.5mm）で配置。**タップは出さない**。接続点は各巻線の左右で**計4点** |
| `coilsCore` | 2巻き変圧器・巻線形＋磁心（JIS 06-09-02） | 上記＋巻線間に磁心の直線1本 |
| `circles3` | 3巻き変圧器・円形（JIS 06-09-04） | **新規**。半径3.4mmの円3個を一辺5.0mmの正三角形状（上1個・下2個）に重ねる。上の円から上へ1本、下の2円から下へ1本ずつの**計3接続点** |
| `coils3` | 3巻き変圧器・巻線形（JIS 06-09-05） | **新規**。上に1巻線・下に2巻線を左右へ並べ、いずれも凸側を内側へ向ける。上巻線の両端から上へ2本、下2巻線の両端から下へ4本の**計6接続点** |

- **06-09-01 と 06-09-02 は同格の2様式**（どちらも「2巻き変圧器（一般用図記号）」）。
  **06-09-04 と 06-09-05 も同様**に「3巻き変圧器（一般用図記号）」の2様式です。マニュアルでもそう説明してください。
- 接続点はすべて**2.5mm格子の倍数**です（17.5 / 5 / 10 / 2.5 mm）。
- **★互換性の注意（マニュアルの注意書きに必要）**:
  JIS形（`circles` / `circlesCore`）は**接続点が6点→2点に変わりました**。
  旧版でこのデザインを使って作図したページでは、左右・上タップに接続していた配線が
  シンボルから外れます。**設備配線用には `standard`（巻線バー＋タップ）を使ってください**。
  JIS形は単線結線図・系統図向けです。
- 内部値は据え置きのため、プロジェクトJSONの読込自体は従来どおり行えます（スキーマ変更なし）。

**修正箇所**

- `docs/manual.md` 1966行目付近の表
  `| 変圧器 | 巻線バー＋タップ（standard） / 二巻線円形JIS（circles） / 二巻線円形＋鉄心JIS（circlesCore） |`
  → 上表の7種に差し替え。
- 1854行目付近「変圧器: 縦の巻線バー2本+タップ端子円…」の説明に、
  JIS形は単線図で接続点数が異なること（2/4/3/6点）と、設備配線には `standard` を使う旨を追記。
- 2058行目付近の寸法表「変圧器 | 手動配置形: 左右15mm、上下9.5mm、上タップ9.5mm上…」に
  JIS形の寸法（円形=ピン間隔17.5mm、巻線形=左右15mm・上下5mm、3巻き円形=下側ピン5mm間隔、
  3巻き巻線形=幅25mm・上下10mm）を追記。

### A-2. リアクトルの磁心線を1本へ是正、旧JIS 2本線を別デザインへ分離

| 値 | 表示名 | 説明 |
|---|---|---|
| `standard` | コイル（JIS 04-03-01・コブ3個） | 変更なし |
| `core` | 磁心入り（JIS 04-03-03・磁心線1本） | **形状是正**。従来の2本線から1本の実線へ |
| `coreOld` | 鉄心入り（旧JIS・2本線） | **新規**。従来の見た目を残したい図面用 |
| `box` | 箱形（IEC） | 変更なし |

- 既存図面で `core` を使っていた箇所は**見た目が1本線に変わります**。従来の2本線に戻すには `coreOld` を選択、
  という案内を入れてください。
- **修正箇所**: 1967行目付近の表、および 436行目「リアクトル（山形コブ3個）」の記述。

### A-3. 接地デザインの名称是正と「機能接地」の追加 ★名称の誤り

円で囲む接地は規格上 **「保護接地」(JIS C 0617-2, 02-15-03)** です。従来「清浄接地」と表示していたのは誤りでした。

| 値 | 旧表示名 | 新表示名 |
|---|---|---|
| `standard` | 斜線ハッチ（設備標準） | 変更なし |
| `bars` | 横棒3本 | **接地・一般（JIS 02-15-01・横棒3本）** |
| `circle` | **清浄接地（円囲み）** ← 誤り | **保護接地（JIS 02-15-03・円囲み）** |
| `functional` | （なし） | **機能接地（JIS 02-15-06・弧囲み）** ← 新規 |
| `chassis` | シャーシ接地（櫛形） | 変更なし |

- 機能接地は保護接地と違い、囲みが**閉じた円ではなく下向きの弧（お椀）**です。この違いを本文で説明してください。
- 内部値 `circle` は互換のため据え置きです（既存図面はそのまま読めます）。
- **修正箇所**: 1958行目付近の表。`清浄接地` の語は本文からも消してください。

### A-4. 負荷開閉器（JIS 07-13-08）の限定図記号を是正 ★形状の誤り

負荷開閉装置の限定図記号（07-01-04）は **小さい「円」** です。従来は**半円**で描き、さらに断路機能の
止め棒を残していたため、規格の形と違っていました。

- 修正後: 固定接点を小円（半径0.9mm）で描き、**断路の止め棒は付けない**（止め棒があるのは断路器 07-13-06 のほう）。
- 寸法・接続点は断路器と共通のままです。
- **修正箇所**: 1983行目付近の表の説明文と、負荷開閉器の形状に触れている箇所。

### A-5. 集計値の更新

- アプリ内ヘルプは「接地4種→**接地5種**」「変圧器3種→**変圧器7種**」「リアクトル3種→**リアクトル4種**」へ更新済みです。
- `docs/manual.md` 1879行目「搭載デザインは合計100種類以上です」は据え置きで問題ありません
  （今回の純増は6様式）。数値を具体的に書いている箇所があれば +6 してください。

## B. 精査して「正しかった」もの（変更不要・マニュアルの記述もそのままでよい）

codex が誤って直さないよう、確認済みの項目を残します。

- **可変抵抗器 04-01-03**: 抵抗器の長方形を左下から右上へ斜めに貫く矢印。
  抵抗の**「可変（`variable`）」が規格どおり**で、追加実装は不要でした。マニュアルの表記も現状のままで構いません
  （番号を書き足すなら「可変（JIS 04-01-03）」）。
- **限時接点 07-05-01〜04**: ∩＝オンディレー（限時動作）、∪＝オフディレー（限時復帰）の割当は規格どおり。
  規格の 07-05-01（メーク・限時閉路）と 07-05-03（ブレーク・限時開路）が同じ限定記号の向き＝オンディレー群、
  07-05-02/07-05-04 がオフディレー群であることと一致します。a接点/b接点×オン/オフの4様式もそろっています。
- **ブザー系 08-10-06 / 08-10-10 / 08-10-09**: 08-10-06＝上ふくらみの半円（弦が下）、08-10-10＝上下反転（弦が上）、
  08-10-09＝頂点が上の三角形。端子線を弦の内側から下ろす描き方も規格どおり。
- **操作機構の限定図記号 02-13-01/03/04/05/08/10/23**: 番号と形（手動＝T字／引き＝⊐／回転＝クランク／
  押し＝⊏＋軸／非常停止＝キノコ半円／足踏み＝斜め踏板／電磁＝箱）はいずれも一致。
- **位置スイッチ 07-08-01 / 07-08-02**、**遮断器 07-13-05（×＋開き線）**、**断路器 07-13-06（止め棒＋開き線）**、
  **接触器主接点 07-13-02（半円の開口が可動接点側）**、**ブリッジ整流 06-14-04**、**接地一般 02-15-01** も一致。
