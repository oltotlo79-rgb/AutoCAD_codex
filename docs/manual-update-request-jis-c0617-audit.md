## A. 今回の変更点（マニュアル修正が必要）

### A-0. シンボルデザイン名の命名基準を新設 ★マニュアル全体の表記に影響

デザイン名がバラバラだったので、**全選択肢を次の基準へ統一**しました。マニュアルの表もこの表記に合わせてください。

> **`名称（出典・形の特徴）`**
>
> 1. 括弧は**全角（）**、括弧内の区切りは**中黒・**。半角 `()` やスラッシュは使わない。
> 2. **出典**は次のいずれか。
>    | 出典 | 意味 |
>    |---|---|
>    | `JIS NN-NN-NN` | JIS C 0617 の図記号番号。**規格名「C 0617」は書かない**（アプリ全体の前提のため冗長） |
>    | `設備標準` | 見本PDFの設備様式（実測形） |
>    | `見本形` | 見本PDF由来だが設備標準の主形ではないもの |
>    | `旧JIS` | JIS C 0301 時代の表記 |
>    | `IEC` | IEC 由来だが JIS 番号を特定していないもの |
>    | `実務形` | 規格外の慣用略画 |
> 3. 出典と特徴が両方あるときは**「出典・特徴」の順**。出典が自明なら特徴だけでよい。
> 4. **JIS番号は規格図と目視照合したものだけ書く。** 未照合のものは番号を書かない。

これに伴い、旧表記 `JIS C 0617 07-08-01` は **`JIS 07-08-01`** に、半角括弧の `可変(矢印)` は
**`可変抵抗器（JIS 04-01-03・貫通矢印）`** に、といった具合に全選択肢を書き換えています。

**新しく JIS 番号が付いた（＝目視照合した）主なデザイン**

### A-1. 遮断器（JIS 07-13-05）の✕の位置を是正 ★形状の誤り

規格 07-13-05 は、メーク接点（07-02-01）の**固定接点**へ遮断機能の限定図記号（07-01-02＝✕）を重ねた形です。
**✕の中心は「可動線のちょうつがいと反対側」にある固定接点の先端**にあり、固定側リードはその中心で終わります。

- **旧**: ✕が可動線の**ちょうつがい（根元）側**に付いていた。
- **新**: ✕を**固定接点側（可動線の先端が向かう側）**へ移動。固定リードは✕の中心で終わり、✕の腕がその先へはみ出す。
- 寸法・接続点（左右2点・幅12.5mm）は変更なし。
- **修正箇所**: `docs/manual.md` 1983行目付近の遮断器デザイン表と、`×＋開き線（IEC）` の表記
  → **`遮断器（JIS 07-13-05・✕＋斜め線）`** に差し替え。

### A-2. 電磁接触器の主メーク接点（JIS 07-13-02）の半円の向きを是正

すでに `contactor` として実装済みでしたが、半円の位置・向きが規格と違っていました。

- **旧**: 半円が固定接点の**外側**にあり、膨らみが**リードの伸びる向き**を向いていた。
- **新**: 半円を**固定側リードの先端から内側へ載せ**、弦がリードと重なり、**膨らみが可動接点の開く側**を向く形へ。
- 寸法・接続点（左右2点・幅10mm）は変更なし。
- **修正箇所**: 1965行目付近の a接点デザイン表。`接触器主接点（半円・JIS C 0617）`
  → **`電磁接触器の主メーク接点（JIS 07-13-02・半円）`**。

### A-3. 変圧器の JIS 形を規格の単線図どおりに作り直し、3巻き2種を追加 ★破壊的変更あり

変圧器のシンボルデザインが **3種 → 7種**。JIS C 0617 の変圧器は**単線図**（各巻線から必要な本数だけ線を出す形）で
規定されており、従来のように「左右4ピン＋上タップ2本」を一律に生やす形は規格と異なっていました。

| 値 | 表示名 | 形状と接続点 |
|---|---|---|
| `standard` | 巻線バー＋タップ（設備標準） | 変更なし。左右15mm・上下9.5mm・上タップ2本の**6接続点** |
| `circles` | 2巻き変圧器・円形（JIS 06-09-01） | 縦に重なる円2個（半径3.4mm・中心間4.0mm＝直径の約4割が重なる）。上の円の上へ1本／下の円の下へ1本だけ。**接続点2点**、ピン間隔17.5mm |
| `circlesCore` | 2巻き変圧器・円形＋磁心（JIS 06-09-01） | 上記＋巻線間に磁心の**直線1本** |
| `coils` | 2巻き変圧器・巻線形（JIS 06-09-02） | 半円コブ4個（半径1.25mm）の巻線2組を**凸側が向かい合う向き**に、巻線間5mmで配置。タップなし。**接続点4点** |
| `coilsCore` | 2巻き変圧器・巻線形＋磁心（JIS 06-09-02） | 上記＋磁心の直線1本 |
| `circles3` | 3巻き変圧器・円形（JIS 06-09-04） | 半径3.4mmの円3個を一辺5.0mmの正三角形状（上1・下2）に重ねる。**接続点3点** |
| `coils3` | 3巻き変圧器・巻線形（JIS 06-09-05） | 上に1巻線・下に2巻線。上へ2本・下へ4本の**接続点6点** |

- **06-09-01と06-09-02は同格の2様式**（どちらも「2巻き変圧器（一般用図記号）」）。**06-09-04と06-09-05も同様**。
- **★互換性の注意（マニュアルの注意書きに必要）**: JIS形（`circles`/`circlesCore`）は**接続点が6点→2点**に変わりました。
  旧版でこのデザインを使ったページでは、左右・上タップに接続していた配線がシンボルから外れます。
  **設備配線には `standard`（巻線バー＋タップ）を使い、JIS形は単線結線図・系統図向け**と案内してください。
- **修正箇所**: 1966行目付近の表を上表の7種へ。1854行目付近の変圧器説明に接続点数の違いを追記。
  2058行目付近の寸法表へ JIS形の寸法（円形=ピン間隔17.5mm、巻線形=左右15mm・上下5mm、
  3巻き円形=下側ピン5mm間隔、3巻き巻線形=幅25mm・上下10mm）を追記。

### A-4. リアクトルの磁心線を1本へ是正、旧JIS 2本線を別デザインへ分離

| 値 | 表示名 |
|---|---|
| `standard` | コイル（JIS 04-03-01・コブ3個） |
| `core` | 磁心入りインダクタ（JIS 04-03-03・磁心線1本）※**2本線から是正** |
| `coreOld` | 鉄心入りリアクトル（旧JIS・2本線）※**新規**（従来の見た目を残したい図面用） |
| `box` | リアクトル（IEC・箱形） |

- 既存図面で `core` を使っていた箇所は**見た目が1本線に変わります**。従来へ戻すには `coreOld` を選択、と案内してください。
- **修正箇所**: 1967行目付近の表、436行目「リアクトル（山形コブ3個）」。

### A-5. 接地デザインの名称是正と「機能接地」の追加 ★名称の誤り

円で囲む接地は規格上 **「保護接地」(JIS 02-15-03)** です。従来「清浄接地」と表示していたのは誤りでした。

| 値 | 旧表示名 | 新表示名 |
|---|---|---|
| `standard` | 斜線ハッチ（設備標準） | 変更なし |
| `bars` | 横棒3本 | 接地・一般（JIS 02-15-01・横棒3本） |
| `circle` | **清浄接地（円囲み）** ← 誤り | **保護接地（JIS 02-15-03・円囲み）** |
| `functional` | （なし） | **機能接地（JIS 02-15-06・弧囲み）** ← 新規 |
| `chassis` | シャーシ接地（櫛形） | シャーシ接地（実務形・櫛形） |

- 機能接地は保護接地と違い、囲みが**閉じた円ではなく下向きの弧（お椀）**です。この違いを本文で説明してください。
- 内部値 `circle` は互換のため据え置きです。
- **修正箇所**: 1958行目付近の表。`清浄接地` の語は本文からも消してください。

### A-6. 負荷開閉器（JIS 07-13-08）の限定図記号を是正 ★形状の誤り

負荷開閉装置の限定図記号（07-01-04）は**小さい「円」**です。従来は**半円**で描き、さらに断路機能の止め棒を残していました。

- 修正後: 固定接点を小円（半径0.9mm）で描き、**断路の止め棒は付けない**（止め棒があるのは断路器 07-13-06）。
- **修正箇所**: 1983行目付近の表の説明文と、負荷開閉器の形状に触れている箇所。

### A-7. 集計値の更新

- アプリ内ヘルプは「接地4種→**5種**」「変圧器3種→**7種**」「リアクトル3種→**4種**」へ更新済み。
- 1879行目「搭載デザインは合計100種類以上です」は据え置きで問題ありません（今回の純増は6様式）。
