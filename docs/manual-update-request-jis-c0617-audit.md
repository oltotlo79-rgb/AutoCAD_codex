## A. 実装済み（マニュアル修正が必要）

すべて参照図を拡大して目視照合し、`npm run check` と Playwright 124件パスを確認済みです。

### A-1. 操作機構の限定図記号 ★番号レベルの誤り

| geoキー | 旧 | 新（規格どおり） |
|---|---|---|
| `operatorManual` | ⊓（両端を軸側へ折った形）＝実際は 02-13-05 | **横棒のみ**（JIS 02-13-01 作動装置・手動一般） |
| `operatorPush` | 横棒のみ＝実際は 02-13-01 | **⊓**（両端を操作軸と同じ側へ折る。JIS 02-13-05 押し操作） |
| `operatorRotate` | 横棒＋上向き半円ドーム | **クランク（Z形）**（左端を上・右端を下へ折る。JIS 02-13-04 回転操作） |

- **`operatorManual` と `operatorPush` は形が入れ替わっていました。**
- `operatorRotate` のドームは 02-13-08（非常操作のキノコ）とほぼ同形で、実図面で誤読される形でした。
- **修正箇所**: 1997行目付近「操作機構の限定図記号」の表。表示名は変更していませんが、
  マニュアルに形状の説明があれば差し替えが必要です。

### A-2. 機能接地（JIS 02-15-06）の弧が上下逆

- 規格は接地3本棒を**上に膨らむドーム（∩）が覆う**形。実装は**お椀（∪）が下**にあり天地が逆でした。
- `arc(2, 2.1, 1.9, 0, 180)` → `arc(2, 3.9, 1.9, 180, 360)` に修正。
- **修正箇所**: 1958行目付近の接地デザイン表の説明文（「弧囲み」の向き）。

### A-3. 2巻き変圧器・巻線形（JIS 06-09-02）の引出線を規格どおり縦へ

- 規格図は**巻線の両端で直角に曲げ、上巻線は上・下巻線は下へ縦に引き出す**形です。
  実装は左右へ水平に出しており、**同じ巻線形の3巻き（06-09-05）とも流儀が食い違っていました**。
- 修正後: `w=15 h=10`、**接続点は (2.5,0)(12.5,0)(2.5,10)(12.5,10) の4点**（縦横とも10mm間隔）。
- **★互換性**: 巻線形（`coils`/`coilsCore`）の接続点座標が変わります。旧版で使っていた図面は配線が外れます。
- **修正箇所**: 1966行目付近の変圧器デザイン表と 2058行目付近の寸法表。

### A-4. 2巻き変圧器・円形（JIS 06-09-01）の円の重なりを規格比率へ

- 規格実測は 円中心間距離 / 直径 = **0.618**。実装は 0.588 でわずかに重なりが深すぎました。
- 円中心を y=6.75/10.75 → **6.65/10.85**（中心間 4.0→4.2mm）へ。引出線は上下とも3.25mmで対称。
- 寸法・接続点（ピン間隔17.5mm・2点）は不変です。

## B. 参照資料についての注意（重要）

### B-1. 参照サイトの 05-03-06 / 05-03-07 は名称と図が逆

行と画像ファイルの対応は正しい（06行→06.png）のに、**図が電気的に名称と合っていません**。

| 番号 | サイトの名称 | サイトの図 | 電気的に正しい対応 |
|---|---|---|---|
| 05-03-06 | 双方向性降伏ダイオード | 三角1個＋片折れバー | ← これは**一方向性**の形 |
| 05-03-07 | 一方向性降伏ダイオード | 三角2個（頂点対向）＋両折れバー | ← これは**双方向性**の形 |

当アプリのラベルは**名称ベースで正しい**ので変更不要です。図形だけ C-1 のとおり直します。

### B-2. 拡大せずに判定してはいけない

参照画像は 40〜120px 程度と小さく、等倍では半円の向き・折れ足の左右・矢の有無が判別できません。
`scratchpad/zoom-refs.js`（`OUT=<path>` で出力先指定）で拡大してから目視してください。
**出力ファイル名を固定にすると並列作業で他プロセスの画像を読む事故が起きます**（実際に発生しました）。
