## A. 電磁接触器（JIS 07-13-02）をパレット部品として新設

### A-1. これまでの問題

`07-13-02` の名称は規格上「**電磁接触器、電磁接触器の主メーク接点**」で、記号そのものが電磁接触器です。
ところがアプリでは **a接点のデザイン選択肢のひとつ**（`contactNO` の `contactor`）にしか無く、
パレットに「電磁接触器」という部品が存在しませんでした。

### A-2. 追加した部品

| 項目 | 値 |
|---|---|
| 種別（内部値） | `contactor` |
| パレット表示名 | **電磁接触器** |
| パレットのカテゴリ | 接点・スイッチ（`contact`） |
| 既定タグ接頭辞 | **`MC`** |
| 既定ラベル | `MC` |
| 既定寸法 | 10 × 4.4mm（a/b接点と共通） |
| 接続ピン | 左 `(0, 2.2)` / 右 `(10, 2.2)`＝**左右ピン間隔10mm**（a/b接点と共通） |
| 接点方向 | 横向き標準／縦配線上の回転配置用（a/b接点と同じ） |
| 参照番号 | 空欄ならコイルから自動（a/b接点と同じ） |

既存の `contactNO` の `contactor` デザインは互換のためそのまま残しています。

### A-3. デザイン（シンボルデザイン）2種

| 値 | 表示名 | 形状 |
|---|---|---|
| `standard` | 電磁接触器の主メーク接点（JIS 07-13-02・半円） | メーク接点（07-02-01）の斜め可動線＋固定側リードに載る半円 |
| `nc` | 電磁接触器のブレーク接点（JIS 07-13-02系・半円＋止め） | ブレーク接点（07-02-03）の斜め可動線＋止め棒＋同じ半円 |

半円（接触器機能の限定図記号）の描き方は両方とも共通です。

- **弦は固定接点側のリードに重なり、ふくらみは可動接点の開く側**（＝可動線のある側）を向く
- 半径 0.7mm、弦 1.4mm

規格図（21×116px の縦向き）の実測では、半円の弦は記号全長の **15.5%**、半径は **7.8%** でした。
本アプリの記号全長10mmに対して弦1.4mm（14%）・半径0.7mm（7%）で、規格比とほぼ一致します。

> b接点側は規格に固有番号を確認できていないため、デザイン名は「**JIS 07-13-02系**」と表記しています
> （番号を断定していない、というマニュアルの表記ルールどおりです）。

### A-4. クロス参照

`contactor` は**コイルの子（接点）**として扱われます。同じタグのコイルとの相互ジャンプ、
図枠のクロス参照表、参照番号の自動表示がa/b接点と同じように働きます。
**`nc` デザインは「閉（b接点）」として判定**され、コイル側の接点一覧では末尾に `b` が付きます。

### A-5. マニュアルへの反映（具体箇所）

1. **§「配置できる部品」の箇条書き**（`docs/manual.md` の「- 接点ブロック」の前あたり）へ1行追加:

   ```markdown
   - 電磁接触器（JIS 07-13-02。主メーク接点／ブレーク接点。既定タグ `MC`、コイルとのクロス参照対応）
   ```

2. **§「接点・操作スイッチ」のデザイン表**へ1行追加:

   ```markdown
   | 電磁接触器 | 主メーク接点・JIS 07-13-02（半円、`standard`） / ブレーク接点・JIS 07-13-02系（半円＋止め、`nc`） |
   ```

3. **§「部品タグ規則」の接頭辞の箇条書き**（`- 押しボタン: PB` などの並び）へ1行追加:

   ```markdown
   - 電磁接触器: `MC`
   ```

4. **§「接続ピンの正規化」の表**の「a/b接点、限時接点…」の行に電磁接触器を含める
   （左右ピン間隔10mm）。

## B. 切替スイッチの回転操作（JIS 02-13-04）の形と位置を是正

### B-1. 何が間違っていたか

2点あります。

1. **形**: 切替スイッチのJIS形（`selectorSwitch` の `jis`）に付く回転操作の作動装置が、
   **横棒の片側だけを折ったL形**になっていました。規格 02-13-04 は
   **横棒の両端を互いに反対向きへ折ったS字（Z字）のクランク**です。
2. **位置**: そのS字のクランクを**接点線の上**に描いていました。正しくは**接点線の下**です
   （**a接点・b接点とも**）。

### B-2. 規格図の実測

`JIS_C0617-02-13-04.png`（59×21px、規格は開閉器を縦向きに描くので棒も縦）:

| 実測項目 | 画素 | 比 |
|---|---|---|
| クランクの棒（芯線） | 19px | 1.00 |
| 上端の折れ脚（連動線と同じ側へ） | 9.5px | 0.50 |
| 下端の折れ脚（反対側へ） | 10px | 0.53 |
| 連動線（破線）の取り付き位置 | 棒の中央 | — |

同じ表の 02-13-05（押し動作）も棒19px・脚10pxで、**脚は棒の約半分**という比率は共通でした。
つまり「両端が折れていること」と「脚が棒の半分あること」の2点が規格形の要件です。

### B-3. 作動装置は接点線の「下」

規格図は開閉装置を**縦向き**（電流路が縦・作動装置が左）に描きます。これを電流路が
**左→右**になるように**反時計回りへ90度**回すと、作動装置は**下**へ来ます。本アプリの
切替スイッチはこの向きを採り、**a接点・b接点とも作動装置を接点線の下**に描きます。

機械連動の破線は、**可動接点から接点の開き間隔（左リードの端 x=3.9 と右リードの端 x=6.1 の間）を
通って下の作動装置へ降ります**。導線と交差しないので、線が重なって読みにくくなることはありません。

### B-4. 修正後の作画（`selectorSwitchJis` / `selectorSwitchJisNc`、記号ローカル座標mm）

```
接点線  : y = 3.2（左リード 0→3.9 / 右リード 6.1→10）
可動接点: a接点 (3.9,3.2) → (6.4,1.6) ／ b接点 (3.9,3.2) → (6.6,1.5)＋止め棒
連動線  : line (5.0,2.5) → (5.0,4.8) 破線 0.8/0.6   ← 可動接点から下へ
クランク: pline (4.1,3.9) → (4.1,4.8) → (5.9,4.8) → (5.9,5.7)
```

- 棒 1.8mm、脚 0.9mm ＝ **比 0.50**（規格実測どおり）
- **左脚は連動線と同じ上向き、右脚は反対の下向き**（規格図を反時計回りに90度回した向き）
- 脚のx位置（4.1 と 5.9）は接点の開き間隔の内側なので、リード線とぶつかりません
- 連動（機械的連結）は規格どおり**破線**。短い区間でも破線と分かるよう `0.8 0.6` とし、
  **可動接点側から描き始めて**接点に確実に接するようにしています
- 外形（10×5mm）と接続ピン（左右 y=3.2、10mm間隔）は**変えていない**ので、
  既存図面の配線はずれません。作動装置が枠の下へ0.7mmはみ出しますが、
  従来（上へ0.5mmはみ出し）と同じ扱いです

### B-5. 作動装置マーク（限定図記号）側も同じ比率へ

パレットの「操作機構（JIS 限定図記号）」→「回転操作（JIS 02-13-04）」（`operatorMark` の `rotate`）も、
両端折れは元から正しかったものの**脚が棒の0.24倍しかなく**S字に見えていませんでした。
規格比 0.5 へ直しています。

```
クランク: pline (1.5,5.0) → (1.5,2.5) → (6.5,2.5) → (6.5,0.0)   棒5.0mm / 脚2.5mm
操作軸  : line (4.0,2.5) → (4.0,8.0)
```

同じ表の手動（02-13-01）・押し（02-13-05）・引きの作動装置マークは**今回変更していません**。

なお `operatorMark` の `rotate` は**単独で置く限定図記号**で、操作軸が下へ伸びて接点の上に重ねる
使い方です。向きの前提が違うので**位置は変えていません**（脚の比率だけ規格へ合わせました）。

### B-6. マニュアルへの反映

§「シンボルデザイン」の切替スイッチの説明（現在は「位置表示は注記として必要な場合に別部品で配置します」
と書かれている段落）を、次の趣旨へ書き換えてください。

> 切替スイッチのJIS形に付く回転操作の作動装置（JIS 02-13-04）は、横棒の両端を互いに反対向きへ折った
> S字のクランクで表し、**接点線の下**に描きます（**a接点・b接点とも**）。棒に対する折れ脚の長さは
> 規格図の実測比（1:0.5）に合わせています。作動装置と可動接点は、機械的連結を示す破線でつなぎます。
> 破線は接点の開き間隔を通るので、導線と交差しません。

既定は従来どおり `jis` です。

### C-3. b接点（`jisNc`）の作画

ブレーク接点は JIS 07-02-03 どおり「**固定接点の先端に導線と直交する止め棒**を立て、
斜めの可動線がその止めに当たって閉じている」形です。a接点との違いは止め棒と可動線の傾きだけで、
**外形寸法・接続ピンはa接点と完全に同じ**なので、切り替えても配線はずれません。

```
左リード  : line (0,3.2) → (3.9,3.2)
右リード  : line (6.1,3.2) → (10,3.2)
止め棒    : line (6.1,1.7) → (6.1,3.2)
可動線    : line (3.9,3.2) → (6.6,1.5)
```

### C-4. 操作位置表示の読み方（マニュアルに必ず書いてください）

操作位置表示つきのデザインは、スイッチ本体（左10mm）の右側に**位置ごとの縦線**を10mm間隔で並べ、
線の上に位置の名称を書きます。**その位置で接点が閉じる**ことを、接点の行を囲む**小さな長方形**で示します。

| デザイン | 位置線 | 閉じる位置（長方形が付く位置） |
|---|---|---|
| `jisOnOff` / `jisNcOnOff` / `keyOnOff` | 切・入 | 入 |
| `threeOnOff` | 入1・切・入2（中央が切） | 入1 と 入2 |

**重要**: 位置表示は**記号の見た目だけが右へ伸び、接続ピンは表示なしの版とまったく同じ**
（左 `(0,3.2)` / 右 `(10,3.2)`）です。表示あり／なしを切り替えても、
接続済みの配線はその場に残ります。位置名称は図記号の一部として固定で、部品側では変更できません
（別の名称にしたい場合は表示なしのデザインを選び、文字部品を重ねてください）。

## R. ラベルの文字サイズを既定2.2mmへ統一

### R-1. 指摘と原因

> シンボルにラベルを付けると文字サイズ2.2で表示されるが、ラベル入力時に文字サイズ2.2になっていても
> それより小さい文字サイズで表示されるシンボルがある。文字の大きさを修正すると戻る。

右パネル「文字スタイル」の**文字サイズ欄は既定 2.2mm と表示**していましたが、実際の描画は
シンボルごとに個別指定でした（`SYMBOL_GEO` のラベルは 253個中 223個が 2.0mm、17個が 1.8mm、
非geoシンボルは 1.8〜2.6mm）。そのためパネルの表示と描画が食い違い、文字サイズを一度でも
編集すると 2.2mm になって「直った」ように見えていました。

### R-2. 修正

- `labelTextSize(element)` を新設し、**ラベル文字のサイズはここ1か所で決める**ようにしました。
  - 利用者が「文字サイズ」を指定していればその値
  - 未指定なら **2.2mm**（直線・連動破線のラベルだけ従来どおり 2.4mm）
- SVG（`applyLabelPresentation`）・geoシンボルの描画・DXF 出力のすべてがこの関数を通ります。
- `SYMBOL_GEO` のラベル定義から個別の `size:` を**253件すべて削除**しました（もう参照されないため）。
- ラベルの真上に説明行（`descLine`）を置く52個の記号は、文字が 2.2mm になって行間が足りなくなるので
  **説明行を 0.4mm 上へ**動かしました（重なり検査テストで確認）。

### R-3. マニュアルへの反映

§（文字スタイル）に「**ラベルの既定文字サイズは 2.2mm**。右パネルの表示と描画は必ず一致する。
直線・連動破線のラベルだけ 2.4mm」と明記してください。
「シンボルによって既定サイズが違う」という趣旨の記述があれば削除してください。

接続点が片側2点なので、配線の上へ置いても配線を分割しません（`wireBreakingTypes` に入れていません）。
