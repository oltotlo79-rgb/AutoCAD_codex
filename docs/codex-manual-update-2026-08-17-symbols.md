## A. 電磁接触器（JIS 07-13-02）をパレット部品として新設

### A-1. これまでの問題

`07-13-02` の名称は規格上「**電磁接触器、電磁接触器の主メーク接点**」で、記号そのものが電磁接触器です。
ところがアプリでは **a接点のデザイン選択肢のひとつ**（`contactNO` の `contactor`）にしか無く、
パレットに「電磁接触器」という部品が存在しませんでした。

### A-2. 追加した部品

| 項目 | 値 |
|---|---|
| 種別（内部値） | `contactor` |
| パレット表示名 | **電磁接触器** |
| パレットのカテゴリ | 接点・スイッチ（`contact`） |
| 既定タグ接頭辞 | **`MC`** |
| 既定ラベル | `MC` |
| 既定寸法 | 10 × 4.4mm（a/b接点と共通） |
| 接続ピン | 左 `(0, 2.2)` / 右 `(10, 2.2)`＝**左右ピン間隔10mm**（a/b接点と共通） |
| 接点方向 | 横向き標準／縦配線上の回転配置用（a/b接点と同じ） |
| 参照番号 | 空欄ならコイルから自動（a/b接点と同じ） |

既存の `contactNO` の `contactor` デザインは互換のためそのまま残しています。

### A-3. デザイン（シンボルデザイン）2種

| 値 | 表示名 | 形状 |
|---|---|---|
| `standard` | 電磁接触器の主メーク接点（JIS 07-13-02・半円） | メーク接点（07-02-01）の斜め可動線＋固定側リードに載る半円 |
| `nc` | 電磁接触器のブレーク接点（JIS 07-13-02系・半円＋止め） | ブレーク接点（07-02-03）の斜め可動線＋止め棒＋同じ半円 |

半円（接触器機能の限定図記号）の描き方は両方とも共通です。

- **弦は固定接点側のリードに重なり、ふくらみは可動接点の開く側**（＝可動線のある側）を向く
- 半径 0.7mm、弦 1.4mm

規格図（21×116px の縦向き）の実測では、半円の弦は記号全長の **15.5%**、半径は **7.8%** でした。
本アプリの記号全長10mmに対して弦1.4mm（14%）・半径0.7mm（7%）で、規格比とほぼ一致します。

> b接点側は規格に固有番号を確認できていないため、デザイン名は「**JIS 07-13-02系**」と表記しています
> （番号を断定していない、というマニュアルの表記ルールどおりです）。

### A-4. クロス参照

`contactor` は**コイルの子（接点）**として扱われます。同じタグのコイルとの相互ジャンプ、
図枠のクロス参照表、参照番号の自動表示がa/b接点と同じように働きます。
**`nc` デザインは「閉（b接点）」として判定**され、コイル側の接点一覧では末尾に `b` が付きます。

### A-5. マニュアルへの反映（具体箇所）

1. **§「配置できる部品」の箇条書き**（`docs/manual.md` の「- 接点ブロック」の前あたり）へ1行追加:

   ```markdown
   - 電磁接触器（JIS 07-13-02。主メーク接点／ブレーク接点。既定タグ `MC`、コイルとのクロス参照対応）
   ```

2. **§「接点・操作スイッチ」のデザイン表**へ1行追加:

   ```markdown
   | 電磁接触器 | 主メーク接点・JIS 07-13-02（半円、`standard`） / ブレーク接点・JIS 07-13-02系（半円＋止め、`nc`） |
   ```

3. **§「部品タグ規則」の接頭辞の箇条書き**（`- 押しボタン: PB` などの並び）へ1行追加:

   ```markdown
   - 電磁接触器: `MC`
   ```

4. **§「接続ピンの正規化」の表**の「a/b接点、限時接点…」の行に電磁接触器を含める
   （左右ピン間隔10mm）。

## B. 切替スイッチの回転操作（JIS 02-13-04）の形を是正

### B-1. 何が間違っていたか

切替スイッチのJIS形（`selectorSwitch` の `jis`）に付く回転操作の作動装置が、
**横棒の片側だけを折ったL形**になっていました。規格 02-13-04 は
**横棒の両端を互いに反対向きへ折ったS字（Z字）のクランク**です。

### B-2. 規格図の実測

`JIS_C0617-02-13-04.png`（59×21px、規格は開閉器を縦向きに描くので棒も縦）:

| 実測項目 | 画素 | 比 |
|---|---|---|
| クランクの棒（芯線） | 19px | 1.00 |
| 上端の折れ脚（連動線と同じ側へ） | 9.5px | 0.50 |
| 下端の折れ脚（反対側へ） | 10px | 0.53 |
| 連動線（破線）の取り付き位置 | 棒の中央 | — |

同じ表の 02-13-05（押し動作）も棒19px・脚10pxで、**脚は棒の約半分**という比率は共通でした。
つまり「両端が折れていること」と「脚が棒の半分あること」の2点が規格形の要件です。

### B-3. 修正後の作画（`selectorSwitchJis` / `selectorSwitchJisNc`、記号ローカル座標mm）

```
クランク: pline (4.0,1.5) → (4.0,0.5) → (6.0,0.5) → (6.0,-0.5)
連動線  : line (5.0,0.5) → (5.0,2.5) 破線 0.8/0.6
```

- 棒 2.0mm、脚 1.0mm ＝ **比 0.50**（規格実測どおり）
- 棒は記号全長10mmの20%（規格図は 20/116 ≒ 17%）
- **左脚は連動線と同じ下向き、右脚は反対の上向き**（規格図を横向きへ写した向き）
- 連動（機械的連結）は規格どおり**破線**。短い区間でも破線と分かるよう `0.8 0.6` にしています

### B-4. 作動装置マーク（限定図記号）側も同じ比率へ

パレットの「操作機構（JIS 限定図記号）」→「回転操作（JIS 02-13-04）」（`operatorMark` の `rotate`）も、
両端折れは元から正しかったものの**脚が棒の0.24倍しかなく**S字に見えていませんでした。
規格比 0.5 へ直しています。

```
クランク: pline (1.5,5.0) → (1.5,2.5) → (6.5,2.5) → (6.5,0.0)   棒5.0mm / 脚2.5mm
操作軸  : line (4.0,2.5) → (4.0,8.0)
```

同じ表の手動（02-13-01）・押し（02-13-05）・引きの作動装置マークは**今回変更していません**。

### B-5. マニュアルへの反映

§「シンボルデザイン」の切替スイッチの説明（現在は「位置表示は注記として必要な場合に別部品で配置します」
と書かれている段落）を、次の趣旨へ書き換えてください。

> 切替スイッチのJIS形に付く回転操作の作動装置（JIS 02-13-04）は、横棒の両端を互いに反対向きへ折った
> S字のクランクで表します。棒に対する折れ脚の長さは規格図の実測比（1:0.5）に合わせています。
> 作動装置と可動接点は、機械的連結を示す破線でつなぎます。

## C. 切替スイッチのデザインを3種→8種へ（b接点・操作位置表示）

### C-1. これまでの問題

- JIS 02-13-04 の切替スイッチに **a接点（メーク接点）しか無かった**
- 「切／入」などの**操作位置表示を持つデザインが無かった**（設備標準の入切表示形は廃止済みで、
  参照されない死んだ定義として残っているだけでした → §D）

### C-2. 追加後の一覧

| 値 | 表示名 | 内容 | 記号の幅 |
|---|---|---|---|
| `jis` | 2位置・a接点（JIS 02-13-04・回転操作） | メーク接点 07-02-01 ＋ 回転操作 | 10mm |
| `jisNc` | 2位置・b接点（JIS 02-13-04・回転操作） | **新規**。ブレーク接点 07-02-03 ＋ 回転操作 | 10mm |
| `jisOnOff` | 2位置・a接点＋操作位置表示（JIS 02-13-04・切／入） | **新規** | 30mm |
| `jisNcOnOff` | 2位置・b接点＋操作位置表示（JIS 02-13-04・切／入） | **新規** | 30mm |
| `three` | 3位置（一般形） | 従来どおり | 10mm |
| `threeOnOff` | 3位置＋操作位置表示（一般形・入1／切／入2） | **新規** | 40mm |
| `key` | 鍵付き（一般形） | 従来どおり | 10mm |
| `keyOnOff` | 鍵付き＋操作位置表示（一般形・切／入） | **新規** | 30mm |

既定は従来どおり `jis` です。

### C-3. b接点（`jisNc`）の作画

ブレーク接点は JIS 07-02-03 どおり「**固定接点の先端に導線と直交する止め棒**を立て、
斜めの可動線がその止めに当たって閉じている」形です。a接点との違いは止め棒と可動線の傾きだけで、
**外形寸法・接続ピンはa接点と完全に同じ**なので、切り替えても配線はずれません。

```
左リード  : line (0,3.2) → (3.9,3.2)
右リード  : line (6.1,3.2) → (10,3.2)
止め棒    : line (6.1,1.7) → (6.1,3.2)
可動線    : line (3.9,3.2) → (6.6,1.5)
```

### C-4. 操作位置表示の読み方（マニュアルに必ず書いてください）

操作位置表示つきのデザインは、スイッチ本体（左10mm）の右側に**位置ごとの縦線**を10mm間隔で並べ、
線の上に位置の名称を書きます。**その位置で接点が閉じる**ことを、接点の行を囲む**小さな長方形**で示します。

| デザイン | 位置線 | 閉じる位置（長方形が付く位置） |
|---|---|---|
| `jisOnOff` / `jisNcOnOff` / `keyOnOff` | 切・入 | 入 |
| `threeOnOff` | 入1・切・入2（中央が切） | 入1 と 入2 |

**重要**: 位置表示は**記号の見た目だけが右へ伸び、接続ピンは表示なしの版とまったく同じ**
（左 `(0,3.2)` / 右 `(10,3.2)`）です。表示あり／なしを切り替えても、
接続済みの配線はその場に残ります。位置名称は図記号の一部として固定で、部品側では変更できません
（別の名称にしたい場合は表示なしのデザインを選び、文字部品を重ねてください）。

### C-5. マニュアルへの反映

1. **§「検出・選択スイッチ」のデザイン表**の切替スイッチの行を差し替え:

   ```markdown
   | 切替スイッチ | 2位置・a接点 JIS 02-13-04（`jis`） / 2位置・b接点 JIS 02-13-04（`jisNc`） / 2位置・a接点＋操作位置表示（`jisOnOff`） / 2位置・b接点＋操作位置表示（`jisNcOnOff`） / 3位置（`three`） / 3位置＋操作位置表示（`threeOnOff`） / 鍵付き（`key`） / 鍵付き＋操作位置表示（`keyOnOff`） |
   ```

2. その直後の段落（「位置表示は注記として必要な場合に別部品で配置します」）を、§B-5 の文章と
   §C-4 の読み方へ差し替え。「別部品で配置します」という記述は**もう正しくありません**。

3. **§「接続ピンの正規化」の表**へ1行追加:

## E. 遮断器の設備標準2種（円＋アーク＋トリップ／円＋アーク）を復活

### E-1. 経緯

2026-08-07〜08 の JIS C 0617 精査で「JIS の遮断器は 07-13-05 だけ」と整理した際に、
見本図面の実測形である**円＋アーク系のデザインを選択肢から外して**いました。
盤図の実務でこの形が必要なため、**選択肢として復活**させます。

### E-2. 復活したデザイン

| 値 | 表示名 | 形状 |
|---|---|---|
| `iec` | 遮断器（JIS 07-13-05・✕＋下開き斜め線） | 既定。変更なし |
| `standard` | 遮断器（設備標準・円＋アーク＋トリップ） | **復活**。端子円2個＋上向きの弧＋右側のトリップ段差 |
| `arc` | 遮断器（設備標準・円＋アーク） | **復活**。端子円2個＋上向きの弧のみ（トリップ段差なし） |

- 3デザインとも**外形12.5×5mm、接続ピンは左 `(0,3)` / 右 `(12.5,3)` の左右12.5mm間隔**で共通です。
  既存図面のまま様式だけ切り替えられ、配線はずれません。
- `standard` のトリップ段差は、`(8.4,3)` から上へ1.1mm → 右へ1.0mm → 下へ2.2mm → 右へ0.8mm → 上へ1.1mm
  という7点のポリラインです。見本図面のCP3で確認した「上に出てから下へ抜ける段差」と同じ形です。
- 定格表示（右パネルの「定格表示(トリップ素子上)」）は3デザインとも段差の上に出ます。

> **箱形MCCB（`mccb`）・漏電遮断器（`elb`）・アーチ形CP（`cp`）は復活させていません。**
> 選択肢に出ないままです。

### E-3. 旧図面の扱い

スキーマ移行（v7→v8）は、これまで遮断器のデザインをすべて `iec` へ寄せていました。
今回から **`standard` と `arc` はそのまま残す**よう変えたので、
古い図面を開いたときに円＋アーク形が JIS 形へ勝手に置き換わることはなくなります。
`mccb` / `elb` / `cp` は選択肢が無いので従来どおり `iec` へ寄せます。

### E-4. マニュアルへの反映

**§「保護部品」のデザイン表**（現在「遮断器 | 遮断器 JIS 07-13-05（`iec`）…」の1行）を差し替え:

```markdown
| 遮断器 | 遮断器 JIS 07-13-05（`iec`。固定接点先端の✕と、下に開く可動斜線） / 遮断器・円＋アーク＋トリップ（設備標準、`standard`） / 遮断器・円＋アーク（設備標準、`arc`） |
```

「遮断器は JIS 07-13-05 形を使用します」と断定している本文（§21 付近）も、
**既定が JIS 形で、見本図面の円＋アーク形も選べる**という書き方へ直してください。

## F. 盤内コンセント・箱形2口の復活と、接地端子つき（3接続点）の追加

### F-1. 見本図面の実測（`見本.pdf` 2ページ目 SC1「制御盤内コンセント」）

箱の外形は **102 × 206px（縦横比 1 : 2.02）**。箱を基準にした各部の位置は次のとおりです。

| 部位 | 位置（箱に対する比） |
|---|---|
| 差込口スロット（左／右） | 幅方向 0.34 / 0.65 |
| 上側の差込口 | 高さ方向 0.17〜0.34 |
| 下側の差込口 | 高さ方向 0.67〜0.84 |
| 接地端子の丸 | **高さ方向 0.51（＝箱の縦中央）**、直径は箱の高さの約0.12 |
| 受電の引出線1 | 箱の**左辺**、高さ方向 0.25 |
| 受電の引出線2 | 箱の**下辺**、幅方向 0.50 |
| 接地の導体 | 端子の丸から**右へ**出て箱の右辺を抜け、外で下へ曲がって接地記号（横棒3本）へ |

**接地は受電とは反対側（右）へ抜ける**、という点がこの記号の要です。

### F-2. 復活・追加したデザイン

| 値 | 表示名 | 内容 |
|---|---|---|
| `boxDouble` | 盤内コンセント・箱形2口（設備標準・受電2接続点） | **復活**。以前の定義のまま。箱＋差込口スロット2組＋内側の接地バー、受電2接続点は左辺 `(0,2)` `(0,12)` |
| `boxDoubleEarth` | 盤内コンセント・箱形2口＋接地端子（設備標準・接地は反対側の3接続点） | **新規**。箱と差込口は `boxDouble` と同一。接地は端子の丸＋導体で表し、**3点目の接続点を右辺 `(12.5,7)`** に持つ |

### F-3. `boxDoubleEarth` の作画（記号ローカル座標mm）

```
外形      : 12.5 × 14mm（箱は rect(2.5, 0, 7.5, 13.5)）
受電ピン  : (0,2) と (0,12)        ← boxDouble と同じ位置
接地ピン  : (12.5,7)               ← 受電2点の左右反対側
差込口    : x=5.2/7.2 の縦線を y=1.8〜4.4 と y=7.4〜10.0 に2組（boxDouble と同一）
接地端子  : circle (6.2, 7, r=0.65)
接地導体  : line (6.85,7) → (12.5,7)   端子の丸から右へ、箱の右辺を抜ける
```

- 接地端子の丸は**箱の縦中央（見本の実測比0.51）**に置いています。`14mm × 0.5 = 7mm` が
  ちょうど2.5mmグリッドに乗るため、接地ピンも `(12.5,7)` でグリッド整合します。
  第1ピン `(0,2)` からの間隔は X 12.5mm・Y 5mm で、**どちらも2.5mmの倍数**です。
- **`boxDouble` にある内側の接地バー（横棒2本）は描きません。** 見本でも接地記号は箱の外にあり、
  こちらは接地線を利用者が引く前提だからです。バーと接地端子を両方描くと、
  「接地が箱の中で終端している」のか「外へ出す端子がある」のかが読めなくなります。
- 受電2点の位置は `boxDouble` と同じなので、**デザインを切り替えても受電側の配線は残り、
  接地ピンだけが増えます**。

> **用語について**: ご指示の「アーク用」は、見本図面のSC1で右側へ抜けている**接地（アース）**の
> 接続点と解釈しました。マニュアルでも「接地端子」と書いてください。

### F-4. マニュアルへの反映

## G. 部品検索が別名・タグ接頭辞・JIS図記号番号でも引けるようにした

### G-1. きっかけと原因

「JIS 07-13-02 電磁接触器のシンボルが見当たらない」という指摘がありました。
調べたところ**記号はパレットに出ていました**（§A で追加した `contactor`。左パネルの
「**接点・スイッチ**」カテゴリの3行目、a接点／b接点／限時a接点／限時b接点の次）。

見つからなかった原因は記号ではなく**部品検索**でした。従来の検索は
**パレットの表示名と種別キーにしか当たらない**ため、実際に打ちそうな語がすべて0件でした。

| 入力した語 | 修正前 | 修正後 |
|---|---|---|
| `電磁接触器` | 1件 | 1件 |
| `接触器` | 1件 | 1件 |
| `MC`（部品タグ接頭辞） | **0件** | 電磁接触器（＋遮断器: MCCB） |
| `コンタクタ` | **0件** | 電磁接触器 |
| `マグネット` / `マグネットスイッチ` | **0件** | 電磁接触器 |
| `電磁開閉器` | **0件** | 電磁接触器 |
| `07-13-02`（JIS図記号番号） | **0件** | 電磁接触器＋a接点（同番号のデザインを持つため） |
| `ブレーカ` / `NFB` | **0件** | 遮断器 |
| `セレクタ` | **0件** | 切替スイッチ |
| `アース` | **0件** | 接地 |

### G-2. 修正内容

部品検索の照合対象を次の5つに広げました。

1. パレットの表示名（従来どおり）
2. 種別キー（従来どおり。例 `contactor`）
3. **部品タグ接頭辞**（例 `MC`。利用者が「部品タグ規則」で変更していればその値）
4. **別名表**（現場での別の呼び方。例「コンタクタ」「マグネットスイッチ」「電磁開閉器」）
5. **シンボルデザイン名に入っている JIS 図記号番号**（例 `07-13-02`）。
   デザイン名の本文までは対象にしていません。本文まで入れると「a接点」で十数件が並んで
   目的の部品が埋もれるためで、**数字の並び（NN-NN-NN）だけ**を機械的に拾っています。

別名は主要部品を一通り登録しています（遮断器＝ブレーカ／NFB／MCCB、切替スイッチ＝セレクタ、
コイル＝リレー／継電器、接地＝アース、サーマルリレー＝過負荷／オーバーロード、
コンセント＝レセプタクル／ソケット、PLC＝シーケンサ、など）。

### G-3. マニュアルへの反映

**§「部品パレット」または §「検索して配置」**に、次の趣旨を追記してください。

> 部品検索は、パレットの表示名だけでなく**現場での別の呼び方・部品タグ接頭辞・JIS図記号番号**にも
> 当たります。たとえば電磁接触器は「電磁接触器」「接触器」「コンタクタ」「マグネットスイッチ」
> 「電磁開閉器」「MC」「07-13-02」のどれでも見つかります。ほかにも「ブレーカ」「NFB」→遮断器、
> 「セレクタ」→切替スイッチ、「アース」→接地、「サーマル」→サーマルリレー、
> 「シーケンサ」→PLC/I-O などが使えます。

**あわせて §「配置できる部品」に、電磁接触器がどのカテゴリにあるかを明記してください**
（左パネル「接点・スイッチ」。a接点・b接点・限時接点の並び）。
